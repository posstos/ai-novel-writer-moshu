## 实现

1. 集中品牌常量、双语窗口标题、启动页、标题栏、首页、关于页、状态栏、助手帮助及工具说明统一显示墨墅。新增本地 SVG / PNG 书房标志与装饰插画，不依赖外网图片。
2. 浅色 / 纸张主题采用米白、墨绿与暖金。保留 dark / galaxy 主题、已有字体偏好、图片皮肤和高对比覆盖规则。
3. 首页重新组织新建、打开、模型配置、指南、参考小说与真实最近项目列表；不编造作品数量、进度或模型在线状态。最近作品可以通过键盘打开。
4. 标题栏去除不可用的备份占位按钮；没有项目时禁用导出。窄窗口保留图标与标题提示，避免工具条溢出。
5. 默认从首页开始，侧栏、AI、任务区按需打开。修正 react-resizable-panels v4 数字被当成像素的问题，使用明确百分比；任务面板收起后真正释放空间，保留任务全局状态和上次展开高度。
6. 设置页改为书房导航与内容双栏，使用现有 Radix 对话框处理焦点、Escape 和关闭后焦点恢复。修复导航 / 状态栏把点击事件误当作 settingsSection 的问题。
7. 内置七部分双语指南：认识软件、连接模型、新建小说、架构蓝图、写第一章、保存导出备份、故障排查。指南本身不发起模型发现或生成请求。
8. 导出对话框和手册明确：仅导出已定稿章节；保存草稿不等于定稿。
