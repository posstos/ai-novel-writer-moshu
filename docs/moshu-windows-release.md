# 墨墅 · Windows 使用与分发说明

本包是墨墅（Moshu）1.2.0 内置双引擎定制版，面向 **Windows 10 / 11、Intel / AMD 64 位电脑**。内置运行库要求 Windows 10 22H2 或更新版本；建议使用已更新的 Windows 10 22H2 或 Windows 11。不支持 Windows 7 / 8.1、32 位系统；不承诺 ARM64 原生兼容。

## 选择一种使用方式

### 安装版

运行 `Moshu-Setup-1.2.0-win-x64.exe`，按向导选择安装目录。默认面向当前用户；安装完成后，从桌面的“墨墅”或开始菜单启动。安装结束不会自动打开写作窗口。

### 免安装便携版

将 `Moshu-Portable-1.2.0-win-x64.zip` **完整解压到本地磁盘**，打开其中的 `Moshu-1.2.0-win-x64` 文件夹，双击 `Moshu.exe`。

- 不要在压缩包内部直接运行。
- 复制到另一台电脑时，复制整个文件夹，不能只复制 EXE。
- `resources`、`locales`、DLL 等都是程序组成部分，不要删除。
- 同一电脑两种版本沿用相同的用户数据身份；不要同时运行多个副本。

## 首次使用

1. 在另一台电脑上解压或安装程序，不需要额外安装 Node.js、pnpm、Python 或 Visual Studio。
2. 程序包含 Electron、SQLite、LanceDB 原生模块及所需的微软 `vcruntime140.dll`。微软运行库仅随程序放置，不安装到系统。
3. 打开墨墅，点“新建小说”创建作品，或“打开作品”选择你自己复制过来的完整项目文件夹。
4. 打开“设置 → AI 生成模型 → 内置本地模型”，导入完整的单文件 GGUF，选择 llama.cpp 或 Ollama、计算设备和上下文，点击“启用并设为默认”。内置模式不需要填写地址或 API Key。向量模型仍单独配置。
5. 阅读首页“使用指南”。生成后先检查改动，再确认写入；退出和迁移前保存作品。

**安装包已包含 Ollama 独立运行库及 llama.cpp（CPU / Vulkan），不包含模型权重、小说或 API Key，也不包含原版 LM Studio。** 每台电脑只需另行准备受支持的完整单文件 GGUF 模型；`127.0.0.1` 表示当前这台电脑，不会自动连接原电脑。模型运行所需内存、显存和磁盘空间另计。夸克网盘下载入口已配置；点击模型下载按钮会在浏览器打开分享页，由用户手动下载后再导入。软件不会登录网盘、读取 Cookie 或绕过下载限制。未配置模型时，可以使用本地项目与编辑功能，但不能进行 AI 生成。

## 内置模型的文件与运行规则

- 推荐先用 llama.cpp：直接读取选中的 GGUF，不额外复制模型。导入只记录文件位置，请放在稳定目录，不要移动或删除原文件。
- Ollama 使用软件自己的模型缓存；第一次导入会校验并导入模型，需要额外磁盘空间，可能耗时较长。
- 自动模式会尝试 GPU；加载失败时尝试 CPU。可手动选“仅 CPU”。实际支持的显卡和模型架构以运行库及驱动为准，不承诺任意 GGUF 都能运行。
- 已有 Ollama / LM Studio 外部连接仍保留；内置引擎使用独立端口和目录，不接管或停止已有服务。
- “停止内置引擎”只停止本软件创建的进程；生成任务进行中请先取消该任务。取消一个写作请求不一定中止共享的模型预加载，需要释放资源时使用停止按钮。
- 夸克链接由程序同目录的 `model-download.json` 配置：当前分享页已填写，提取码留空。仅允许 `https://pan.quark.cn/s/...` 分享页。该入口打开浏览器，由用户下载后再导入，不把分享页当作直链。
- 当前内置导入面向文本生成模型：不直接导入 ZIP、Safetensors 目录、LoRA 补丁或分片 GGUF；需要完整、受对应引擎支持的单文件 GGUF。

## 数据在哪里；怎样换电脑

“便携”指程序免安装，不代表把你的小说和设置自动塞进程序文件夹。

- 作品在你创建或打开时选择的项目目录中。请复制**完整项目文件夹**，不是只复制某一个正文文件。
- 历史全局配置仍默认保存在当前用户的 `%USERPROFILE%\.vela`。
- 内置引擎的登记信息、运行状态与 Ollama 模型缓存位于上述全局配置目录下的 `managed-local`，不包含在安装包内；原始 GGUF 保留在你选择的位置。
- Electron 用户数据仍沿用 `%APPDATA%\ai-novel-writer`，不会因为显示名称改成“墨墅”而自动迁移。
- 设置过 `AI_NOVEL_VELA_HOME` 等覆盖项的电脑，以实际配置的目录为准。
- 同一台电脑升级前，先退出墨墅并备份作品；不要把作品存放在程序安装目录里。
- 换电脑时，先复制作品，再在新电脑中“打开作品”。原来的盘符、最近项目路径和模型服务地址未必适用。
- 如需迁移全局设置，应自行安全备份上述数据目录；其中可能含 API Key 或身份密钥，不要随公开安装包发送。不要覆盖新电脑已有的配置，除非你已做好备份并确认需要替换。
- 卸载配置为保留应用数据，但不能替代备份。删除或重装程序前仍请先保存并备份作品。

## 常见问题

**黑屏、窗口显示异常或显卡驱动较旧：** 本次 Windows 发行版默认采用软件渲染，优先兼容旧显卡、远程桌面与虚拟机，不以关闭 GPU 沙箱来换取启动兼容性。仍可在完全退出墨墅后双击同目录的 `Moshu-Safe-Mode.cmd`，显式附加 `--disable-gpu`。不会关闭沙箱、杀毒软件或修改系统设置；软件渲染可能增加 CPU 占用。仍有问题时检查 Windows 和显卡驱动更新。

**提示缺少 DLL：** 首先确认完整解压，且 `vcruntime140.dll` 和其他运行文件没有被删除或隔离。不要从不明“DLL 下载站”补文件。

**SmartScreen / 未知发布者：** 本定制包没有购买的商业代码签名证书，Windows 可能提示“未知发布者”。先核对分发来源与 SHA-256；仅在确认来源可信后运行，不要关闭杀毒软件或全局安全功能。微软 DLL 的签名不代表整个墨墅安装包已签名。

**模型启动失败：** 内置模式检查 GGUF 完整性、引擎支持的架构、可用内存、驱动和上下文；尝试 CPU 模式或较小模型。外部模式再检查服务端口和模型 ID。本次未下载或运行真实模型，不等于已经验证你的网盘模型。

**更新：** 本定制版采用手动更新，不自动安装上游 AI Novel Writer 版本。请从同一分发来源获取新版墨墅包，以免覆盖定制界面。新包覆盖前先退出并备份。

## 验证范围

请以旁边的 `BUILD-REPORT.json` 和交付清单中的实际结果为准。单台构建电脑上的测试不等于已在多台电脑、所有 Windows 小版本、全部显卡或实际模型上验收。

本流程不自动安装或卸载真实系统中的应用，也不会操作现有小说。安装器进行结构/有效载荷校验；可见安装向导、真实安装/卸载及第二台电脑运行需在目标电脑确认。

建议首次换机验收：完整解压 → 启动 → 打开帮助 → 在自选空目录创建测试作品 → 输入并保存 → 退出再打开 → 单独配置模型并测试连接 → 生成少量测试文本并人工确认。确认后再迁移重要作品。
